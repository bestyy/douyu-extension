# 弹窗在线列表改为左栏分类选择器 + 右侧列表，弹窗宽度 360px 放宽到 460px

房间与分类多起来后，弹窗的在线列表是「分类标题 + 卡片」纵向堆叠的一条长列表，横向分段标题把「一眼看在播」这件小事变成长滚动。改为左侧一栏分类选择器（分类栏）、右侧只显示当前选中分类的在线列表。**这一条推翻了 ADR-0008 的一条成文否决**（「弹窗加分类筛选 chips / 可折叠分段 / 空分类也显示」被否决），因此单独成文记录改口的理由与边界。左栏是纯展示形态的改动：它筛选视图、一个字都不写盘，房间库的四个键一个不增，弹窗仍然是只读的展示面。

**一、推翻 ADR-0008 的依据：被否决的是「操作面」，不是「筛选」。** ADR-0008 当时的理由是「弹窗就是一眼看在播的小窗，加筛选和折叠会把只读展面变成需要操作的面」。本次形态与当时被否决的那一坨（chips + 折叠 + 空分类标题）在三处不同：条目常驻且不折叠；没有开播房间的分类根本不占位，左栏不会把列表撑长；切换只改渲染哪一段，不增删房间、不改分类、不发任何写请求。ADR-0003 的单写者边界一行未动，「只读展示面」的实质（不拥有数据）因此仍然成立——被推翻的是当时对「筛选必然把界面变成操作面」的判断，而不是「弹窗不写数据」这条边界。

**二、宽度加宽到 460px，是为了右侧一寸不让。** 左栏约 100px，右侧卡片可用宽度因此与今天完全相同（460 − 100 与原来的 360 相互抵消）：卡片的 44px 头像、信息区约 267px、今日统计的两行布局、平台标签与观众数一行，全部一行不改。若坚持 360px，信息区会被压到约 183px，分类名（上限 20 字）在 80px 的栏宽里只能显示两三个字，今日统计两行刚好卡边。代价是全窗口一起变宽：头部、选项栏、底部按钮、空态与错误态都跟着变，弹窗不再是小尺寸。设置页不受影响。

**三、左栏条目 = 「全部」+「未分类」+ 有在播房间的分类。** 「全部」置顶，是投影出来的视图聚合：不落盘、不是分类、不可改名删除、不在分类列表里，与「未分类」并列但不是一回事（后者是一个真实的落点，前者只是「不过滤」）。「未分类」沿用 ADR-0008 的虚拟桶语义，只在真有在播的未分类房间时出现。真分类沿用弹窗既有口径——只列出当下有开播房间的那些，顺序即分类列表顺序。每项带该分类的在播数，一眼能比出哪个分类当下更热闹。因为条目会随轮询变化，就有「选中的分类从左栏消失」这种状态，见第六条。

**四、右侧只在「全部」下保留分类标题。** 选中某个具体分类时右侧不再显示分类标题——左栏已经在表达分类，再显示一遍是重复；「全部」视图下仍按分类分段并显示标题，与今天的观感一致。分段标题**不可点**：切分类的唯一入口是左栏，同一件事不开两个入口（沿用 ADR-0008 否决「跨分类拖拽顺带改分类」的同一条理由）。右侧始终只显示开播中的房间——弹窗是「在线列表」，离线房间不出现在这里（这一条沿用 ADR-0008，未变）。

**五、默认选中「记住的上次选中的分类」，这份状态归编排。** 打开弹窗时的选中项是上一次的选择；选中的是分类 id。这份状态**不进房间库的四个键**：房间库拥有的是房间、主播、分类与设置的形状，而「上次点了哪一栏」不是它们的形状的一部分（同 `watchQueued` / `todayStats` 的归属惯例，见 ADR-0003 的键归属声明）。弹窗不写它——页面直写依然禁止，弹窗发消息、SW 转给编排落盘（ADR-0003 的「新增存储键必须先声明归属」照办）。键名与消息类型属实现细节，不在本条 ADR 里钉。

**六、回落只影响本次显示，不改写记忆。** 选中的分类可能失去在播房间（其下房间全下播）从而从左栏消失；分类被删除时同理（记忆里存的是 id，id 失效）。两种情况走同一条规则：本次显示回落到「全部」，记忆保持原值——下次打开时若该分类又有在播房间（或 id 仍然有效），仍选中它。理由是记忆代表用户意图，不该被一次暂时下播抹掉；两种失效来源共用一条规则，也不需要第二套处理。全部分类都无在播房间时，弹窗回到现有的整页空态，左栏不渲染（此时可选条目只剩空集，画出来也不含信息）。

**七、头部计数保持全局口径。** 「在线主播 / 信号条 / N 在线」不随选中分类变化：它是仪表盘（全部在线数 + 档位），左栏是导航（每项自己的在播数）。让头部跟着选中项走，「在线 N」的含义就会随选中项漂移，信号条的档位口径也要跟着换一套，两个地方各说一套计数。

**八、「全部」进入保留名。** 分类名不得等于「全部」，与 ADR-0008 对「未分类」的处理同理：同一栏里出现两个同名条目会让语义分叉。落点是 `lib/room-categories.js` 的名称校验（`validateName`），与「未分类」同处，测例同处。

**九、左栏条目构成是一条纯投影，收进纯模块。** 条目构成与各自在播数由 `lib/room-categories.js` 的纯函数算出（与 `buildRoomGroups` 同行，见 ADR-0005），弹窗只渲染它的结论。它眼下只有弹窗一处消费，但它是 ADR-0008 已经收进那个模块的一条规则（「未分类固定最前」「只留有在播的分类」）的延伸，放在别处会让同一件事在两份代码里各判一次；放进纯模块还能被现有测例直接钉住。

**十、名词：「分类栏」与「内容分类」。** 弹窗左栏及其选中状态在词汇表里叫**分类栏**。卡片上那行裸文字（`streamers[].category`，斗鱼 `cate_name` / B站 `area_name`）此前没有词条，本次补一条**内容分类**：它是平台给的观测量，与用户自建的「分类」是两个词，卡片上不加标签、不改样式。ADR-0008 正文用过「平台给的内容分类」这个说法，词表补上后两者在同一界面里的边界才写得清。

**范围**：设置页不动——它仍是完整列表 + 横向分段标题（含空分类、含全部未开播分类），本次只改弹窗的在线列表形态。

## Considered Options

- **保持 360px、把左栏塞进去**：弹窗尺寸不变；但分类名在 80px 里必然截断成两三个字，右侧信息区压到约 183px（今日统计两行卡边），卡片上的标题与昵称更早出现省略号。取舍是「弹窗保持小尺寸」换「左右两栏一起变窄」，取前者不划算。
- **左栏做成抽屉 / 顶部 chips**：不占常驻宽度，右侧一寸不让；但每次换分类多一次点击，且看不到各分类当下有没有在播。chips 正是 ADR-0008 否决过的形态，形态上等于原地重提。
- **不做「全部」这一项，只列有在播的分类**：概念少一个；但进到某个分类后没有回到全景的落脚点，「未分类」也只是一个平级项——想看全部在播房间就没有地方可回。
- **左栏列出全部分类（含空分类、含全部未开播的）**：左栏位置稳定、不随轮询跳动；但点进空分类只剩一句空态，且与弹窗「只渲染有在播的分类」的既有口径分叉成两条。
- **默认选中固定「全部」**：不新增任何存储键；但常看某一个分类的用户每次打开都要重新点一次，而弹窗的全部价值就是省一步。
- **记忆由弹窗直写 `chrome.storage.session` 或页面 `localStorage`**：省一条消息往返；但 ADR-0003 的键归属声明里没有「页面直写」的例外，且 `session` 不跨浏览器重启——「记住上次选中」只活到关浏览器为止，名不副实。
- **回落时一并改写记忆**：状态只有一份、不会出现「高亮在 A 而记忆是 B」的组合；但一次全下播就把用户的分类偏好清掉，下次还得重新点回去。
- **头部计数随选中分类变化**：上下文更贴；但「在线 N」的含义随选中项漂移，信号条档位也要改成分类口径，且与左栏选中项的徽标重复。
- **分类标题可点、点了切到该分类**：从全景里发现感兴趣的分类能少一步；但同一件事两个入口，标题行要从纯文字变成可点控件（悬停 / 焦点 / 键盘样式都要补）。
- **左栏支持折叠 / 归类 / 改名**：功能更全；但弹窗会变成缩小版设置页，分类管理在设置页已有完整落点（ADR-0008 的「弹窗仍是只读展示面：不在弹窗里归类、改名、删除」不变）。

## Consequences

- ADR-0008 的显示规则一段被本条**部分修订**：设置页那半（完整列表、所有分类、始终显示标题、不折叠）原样成立；弹窗那半的「只渲染有在播房间的分类」成立，「始终显示分类标题」改为「仅在选中『全部』时显示」，「弹窗加分类筛选」这条否决由本条推翻。ADR-0008 的显示规则段与 Considered Options 里已各加一行指向本条。
- 房间库的四个键一个不增；新增一个**归属编排**的键（上次选中的分类 id）与一条页面 → SW 的消息类型。ADR-0003 的键归属声明照办，弹窗仍然不出现 `chrome.storage.local` 的写。
- 「全部」进入保留名后，设置页的分类名校验会多拒一个名字；`lib/room-categories.js` 的 `validateName` 与 `test/room-categories.test.cjs` 要同步。
- 左栏条目构成的新纯函数落在 `lib/room-categories.js`，测例与 `buildRoomGroups` 同处（含「有在播才占位」「全部置顶」「未分类紧随其后」三条口径）。
- 记忆存的是分类 id，分类被删后 id 失效 → 与「全下播」共用同一条回落规则（临时回落、不改记忆），因此不需要第二套失效处理，也不需要额外的 id 回收。
- 弹窗宽度 460px 是全窗口生效：头部、选项栏、底部按钮、空态与错误态一起变宽；左栏与右侧各自独立滚动，因此 460px 内会同时存在两条滚动条。
- 分类**仍然**不触碰任何通知链路（ADR-0008 第六条不变）：左栏只决定看哪一段，不做「整个分类静音」、不参与观众数提醒 / 弹幕激增 / 看点通知的任何判定。
